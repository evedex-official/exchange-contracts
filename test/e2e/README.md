This directory contains a demonstration of the main flow of interacting with Evedex contracts. The purpose is to show how to interact with the core contracts and how the system works. The demo is written in a test-like format.

Usually, tests are contract-oriented in solidity world; however, in this demo, several contracts could be involved in a single test suite to show the flow. Therefore, the test suite can be considered as end-to-end tests.
